# ATM Simulator (HTML/CSS/JS + Java + Aiven MySQL)

## Run
1. Install **JDK 17+** and **Maven**.
2. Edit `config.properties` with your Aiven host, port, user, password
   (Aiven Console > MySQL service > Overview). Keep `?sslMode=REQUIRED`.
3. In Aiven, make sure your IP is allowed (Service > Allowed IP addresses).
4. In this folder run:  `mvn compile exec:java`
5. Open http://localhost:8080 — create an account, then log in.

Tables are created automatically on first start.
